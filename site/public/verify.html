Verify Signing Fingerprints

Each shkriuss app uses its own dedicated RSA-4096 signing key with APK Signature Scheme v3.1, reproducible Gradle builds (no Google Play dependency signing block), and GitHub SLSA Build Level 3 provenance attestations.

How to Verify on GrapheneOS

  1. Download the release APK from GitHub Releases (or track releases via Obtainium).
  2. Open AppVerifier on GrapheneOS and select the downloaded APK or installed app.
  3. Compare the displayed SHA-256 signing certificate fingerprint character-for-character against the table below.

Installing on GrapheneOS vs. Stock Android (2026–2027 Verification Rules)

GrapheneOS: Installs signed open-source APKs normally with zero Google account or Play Protect involvement.

Stock / Certified Android: shkriuss intentionally remains unregistered with Google's Android Developer Verification program to maintain zero runtime or identity dependency on Google. On certified Android devices in regions enforcing Developer Verification, users can still install unregistered FOSS APKs via Android's official Advanced Flow (explicit user confirmation / waiting period) or compile from source and sign with their own key.
