# OWASP MASVS v2.1.0 Control Matrix

This matrix maps the [OWASP Mobile Application Security Verification Standard (MASVS) v2.1.0](https://mas.owasp.org/MASVS/) categories to concrete architectural controls enforced in `shkriuss/shkriuss.dev`.

| MASVS Control | Requirement Summary | shkriuss Implementation | Verification |
| --- | --- | --- | --- |
| **MASVS-STORAGE-1** | Sensitive data stored securely | Tink `AES-256-GCM` AEAD payloads inside Room (OS SQLite) + Tink-encrypted DataStore (`:core:storage`); `allowBackup="false"`, strict `dataExtractionRules`. | Unit tests in `:core:crypto` & `:core:storage`; static manifest audit in `pr-verify.yml`. |
| **MASVS-STORAGE-2** | No sensitive data leaked via logs, caches, clipboard, or screenshots | Zero logging of plaintext/keys/PII; optional `FLAG_SECURE`; ephemeral cache avoidance; streaming SAF I/O for backups/files. | Code review + Lint + `grapheneos-audit` skill. |
| **MASVS-CRYPTO-1** | Strong, current cryptographic algorithms | Tink `AES-256-GCM`, Tink Streaming `AES-256-GCM-HKDF`, Bouncy Castle pure-JVM `Argon2id`; zero deprecated `security-crypto`, zero ECB/SHA-1/MD5/PBKDF2-weak. | Unit tests in `:core:crypto` & `:core:backup`; static dependency check in CI. |
| **MASVS-CRYPTO-2** | Proper key management & random generation | Android Keystore KEK backed by StrongBox (TEE fallback); `SecureRandom` salts/nonces; zero hardcoded keys; immediate `SecureByteArray.close()` zeroization. | Unit tests + security review. |
| **MASVS-AUTH-1 / 2 / 3** | Local & remote authentication | Offline apps require no account. Optional local app lock via `androidx.biometric` / device credential; future optional self-hosted sync uses zero-knowledge authentication without sending encryption keys to server. | App-level auth tests when implemented. |
| **MASVS-NETWORK-1 / 2** | Secure TLS transport & identity verification | Offline apps declare ZERO `INTERNET` permission. Future optional sync uses HTTPS/TLS 1.3 only (`usesCleartextTraffic="false"`, OkHttp `5.5.1` with strict certificate validation and opt-in ECH). | Static manifest audit + Network Security Config. |
| **MASVS-PLATFORM-1 / 2 / 3** | Safe IPC, zero WebView abuse, safe UI | Internal components `exported="false"`; zero WebView anywhere; least-privilege SAF & Photo Picker; safe deep-link validation; Android 17 predictive back and adaptive window handling. | Static CI guardrail scan + Android Lint. |
| **MASVS-CODE-1 / 2 / 3 / 4** | App integrity, reproducible builds, clean dependencies | Reproducible Gradle 9.9 / AGP 9.5 builds (`dependenciesInfo` disabled), R8 minification on release, exact pinned dependencies, SHA-pinned GitHub Actions, SLSA Level 3 provenance, APK Signature Scheme v3.1, zero debuggable releases. | `pr-verify.yml`, `release-app.yml`, AppVerifier fingerprint checks. |
| **MASVS-RESILIENCE** | Explicit non-goal for hostile DRM; openness prioritized | Apps are GPL-3.0-or-later FOSS with zero Play Integrity or anti-root/anti-GrapheneOS checks. Hardening relies on Android/GrapheneOS OS protections (`hardened_malloc`, ARM MTE, DCL restrictions), never obscurity. | Verified against GrapheneOS with Compatibility Mode OFF. |
| **MASVS-PRIVACY-1..4** | Data minimization, transparency, user control | Local-first by default; zero trackers/analytics/GMS; full E2EE export & local deletion; works with `Network` and `Sensors` revoked and inside Private Space / secondary profiles. | Static dependency & permission checks in CI. |
